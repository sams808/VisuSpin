Model: dMx/dt = Δω·My − Mx/T2, dMy/dt = −Δω·Mx − My/T2, dMz/dt = −(Mz−M0)/T1, per isochromat, integrated exactly (not forward Euler). B1 ‖ +x, so a 90°x pulse sends M from +z to −y. The nucleus selector uses real (γ, I, natural abundance) values to set a real Larmor frequency ν0 = γB0/2π, and the inhomogeneous linewidth slider is a real ppm value converted through ν0 — so changing B0 genuinely changes the offset distribution in Hz, exactly as on a real spectrometer. Isochromat offsets are drawn Gaussian per the original spec; the "formula" T2* uses the stated 1/T2* = 1/T2 + Δωinhom/2 relation exactly (that relation is only exact for a Lorentzian offset distribution), while "fit" T2* is a live least-squares fit to ln|ΣMxy(t)| since the last 90° pulse — the two are shown side by side deliberately, so the Gaussian-vs-Lorentzian approximation is visible rather than hidden. For spin I > 1/2, Cq contributes an illustrative Cq²/ν0 second-order-quadrupolar broadening term (a real scaling law — higher field narrows quadrupolar lines — with an illustrative, not compound-specific, prefactor); satellite transitions and the full quadrupolar lineshape are not separately simulated, only the central-transition-like vector sum. Pulses are no longer instantaneous rotations: each 90°/180° pulse is a finite-duration B1 field (real ν1 in kHz, hard or sin²-shaped) applied via the full effective-field rotation, so off-resonance isochromats genuinely tip along a different axis than on-resonance ones — real pulse-imperfection physics, not idealised. Real pulses are microseconds long, far too fast to watch at 1×, so the tip trajectory is explicitly played back over a fixed ~0.9 s window regardless of duration — a deliberate "zoom in", not a claim that it runs at that speed. For half-integer quadrupolar spins (not integer spins like ²H, which have no distinguished central transition), the "Energy levels & RF excitation" panel shows the satellite manifold as a Monte-Carlo powder pattern (η=0, first-order only; every transition powder-averages to exactly the CT frequency, only its width grows with |m−½|) and overlays the pulse's actual excitation profile, computed by running the same rotation physics on swept test offsets so it's guaranteed consistent with the pulse really applied. When the pulse bandwidth sits well inside the satellite manifold the tool reports CT-selective excitation and applies the standard (I+½) nutation-rate enhancement; once the bandwidth covers the satellites too, it reports non-selective excitation and drops the enhancement. DFS (double frequency sweep) is a constant-amplitude pulse whose RF frequency is linearly swept across the satellite manifold — each isochromat crosses resonance with the sweep at a different instant, the actual adiabatic mechanism DFS relies on, not a scripted effect. MAS is a single-harmonic cos(ωrt+φ) modulation of each isochromat's static offset (a simplified stand-in for the real two-harmonic (3cos²θ(t)−1) modulation) — it correctly narrows the decay envelope in the live trace/FFT panels, but that panel's fixed 2 ms sample interval can only resolve sidebands out to ~250 Hz, unrealistically slow for real MAS rates (kHz-scale); the sideband structure itself is shown properly rebinned in the "Energy levels & RF excitation" panel instead, which isn't subject to that sampling limit. That panel now shows a frequency axis, pulse excitation profile, and MAS sidebands for every nucleus, not just quadrupolar ones: half-integer quadrupolar spins get the real multi-transition satellite powder pattern described above, while spin-1/2 and integer-spin nuclei get the same Gaussian (from T2* and the linewidth slider) that's actually driving their isochromat ensemble, so the pattern shown is always tied to real simulated physics, never a placeholder. ¹0;B is included as spin I=3 (integer, quadrupolar, no central transition) — note this is the real value; an earlier request for this nucleus assumed I=1, which is incorrect. Individual isochromats are now drawn after the resultant rather than before, so the thin grey arrows stay visible on top instead of being covered by the thick blue one when they're still nearly coincident (e.g. immediately after a clean pulse, before dephasing has had time to develop).
